This module provides the Liza integration for Odoo.

The module is derived from the OCA `companyweb_base` module, which was
originally developed by [ACSONE](https://acsone.eu) for Odoo version 8,
subsequently enhanced by Jacques-Etienne Baudoux (BCIM sprl), and
redeveloped in 2021 and 2025 to support the SOAP API (v1 and v2). That
work was funded by Companyweb.

The adaptation to the Liza brand has been funded by
[Liza](https://www.liza.nl).
